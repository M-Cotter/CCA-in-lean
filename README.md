# Combinatorial Commutative Algebra in Lean 4

This is a repository dedicated to proving facts about monomial ideals and combinatorial commutative algebra in Lean 4. Primarily, we aim to prove Macaulay's theorem about monomial ideals, which fully characterizes the Hilbert function of homogeneous ideals.

# Structure

The full code and report is available in the CcaInLean folder. This folder contains subfolders, the MonomialIdeals folder is dedicated to proving introductory facts about monomial ideals, including the squarefree-radical correspondence, gradings, colons, minimal generators etc. The Macaulay folder is dedicated to some introductory facts about lex ideals, and the MacaulayAnderson folder follows Ian Anderson's textbook Combinatorics of Finite sets to prove Macaulay's theorem.
